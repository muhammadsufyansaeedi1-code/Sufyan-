# Jarvis Assistant

A local Jarvis-inspired assistant that runs as a small browser app with a Node.js backend.

## Features

- Voice input support (browser dependent)
- Voice output using the built-in browser speech engine
- Local command responses for time, date, status, greetings, and basic system tasks
- Simple dashboard UI inspired by a fictional AI control room

## Run it locally

1. In the project folder, run:
   ```bash
   npm start
   ```
2. Open http://localhost:3000 in your browser.

## Notes

This is a starter assistant. You can extend it by connecting to real APIs, AI services, or additional commands.
